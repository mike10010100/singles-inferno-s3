# Single's Inferno Season 3 Tracker

A simple React-based cheat sheet/tracker for *Single's Inferno* Season 3. 

## Features
- Track who is in **Inferno** and who is in **Paradise**.
- Add notes for each contestant (Age, Job, Feelings, etc.).
- Includes all 12 contestants from Season 3, including late comers.
- Persistent state using LocalStorage.
- Modern, responsive UI with a "Hell vs. Heaven" aesthetic.

## Tech Stack
- React 19
- TypeScript
- Vite
- Lucide React (Icons)
- Vanilla CSS

## How to use
1.  Clone the repo.
2.  Run `npm install`.
3.  Run `npm run dev`.
4.  Open your browser to the local dev server URL.
5.  Click **"Go to Paradise"** to move a contestant to the Paradise section.
6.  Use the **Notes** area to jot down details as they are revealed in the show.
7.  Click the **Lock** icon on late-comer cards to unlock them when they arrive in the show.

## Season 3 Twist
Season 3 features a "Two Infernos" twist at the start, making the tracker even more useful for keeping track of who knows whom!
